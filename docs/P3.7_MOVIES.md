## Runtime pack (P1.6)

Owner `runtime/us` has 13 `.STR` files under `AAA/STR/` (incl.
`MOVIEOPN.STR`, ~37 MiB = 18088 × 2048-byte user sectors). Map marks
`form: 2`. `pack_runtime.py` copies the AAA tree as-is (2048-byte extracts).

**Sector adapter (Wave 3–4):** `port/movies/str_stream.c` synthesizes
Mode2/Form2 **2352-byte** sectors from those 2048-byte payloads (sync +
header + subheader + 2048 user + zero pad). PSY-Z `StCdInterrupt` reads
user data at offset 24. Video magic `0x0160` → submode Data|Form2|RT;
non-video (XA ADPCM) → Audio|Form2|RT + stereo CI `0x01`. Optional
`DW3_DISC_BIN=/path/to/game.bin` (Mode2/2352) supplies full Form2 user
data — packed STR truncates XA at 2048 (16/18 ADPCM blocks); bin restores
all 18.

On this bring-up host, point `runtime/us` at the packed tree (gitignored):

```bash

ln -sfn "$HOME/.cache/dw3-switch/runtime/us" runtime/us
# Owner disc image (not in git):
# /mnt/windows/Jogos/PS1/Digimon World 3/Digimon World 3.bin
```

## Present wave — GPU / DMA / RGB24 (2026-10-10)

Branch: `phase3-movies-present` — **merged** into `phase3-pc-bringup` @ `7db22e6` (PR #6).

### Diagnosis

| Symptom | Cause |
|---|---|
| `SDL_CreateGPUDevice: No supported SDL_GPU backend` | `SDL_VIDEODRIVER=dummy` — use `offscreen` or a real display (`DISPLAY=:0`) |
| Hang after `first frame ready` | PSY-Z `DMACallback` was `NOT_IMPLEMENTED`; `DecDCTout` never raised the MDEC-out IRQ the title player waits on (`STDWTITL_onSliceDecoded` → `isdone`) |
| Nested `LoadImage` stall | `sdl3_gpu` reused one upload transfer buffer without `SubmitCmd` between recursive slice uploads |
| First frame black / wrong colors | Opening STR is 24-bit; GPU `LoadImage` always treated payloads as RGB5551 |

### Host fixes (`platforms/pc`)

| Piece | Where |
|---|---|
| `DMACallback` + fire after `DecDCTout` | `psyz_dma_present.c` (`-Wl,--wrap`) |
| RGB24 halfword→pixel `LoadImage` | same (latch `PutDispEnv.isrgb24` + STR-slice heuristic) |
| Optional PPM dump | `DW3_FB_DUMP=path.ppm` from `psyz_dma_present.c` after first RGB24 frame |
| Transfer-buffer submit | `vendor/psyz/.../sdl3_gpu.c` `Draw_LoadImage` → `SubmitCmd()` |
