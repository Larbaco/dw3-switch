## Call graph (game)

```
newGame / boot
  MODE_OPENING (0xE01) or MODE_OPENING_2 (0xE02) …
    STDWTITL scene → STDWTITL_startMovieTask(movieIndex)
      STDWTITL_tickMovie
        STDWTITL_startMoviePlayerTask(fileId, endFrame)
          FILE_TABLE.getPos(file, 0, &CdlLOC)
          DecDCTReset → StSetRing → StSetStream → CdRead2(stream)
          DecDCTvlcBuild / DecDCTvlc2 / DecDCTin / DecDCTout
          (XA audio via CdlModeRT on the same stream)
        Start or endFrame → pause CD, StUnSetRing, free buffers
      requestMode(nextMode)  # opening → MODE_TITLE
```

US opening file: `STDWTITL_movies[0]` = `{0x7E5, 0x6F0, MODE_TITLE}` →
`AAA/STR/MOVIEOPN.STR` (runtime map `form: 2`).

## Runtime pack (P1.6)

Owner `runtime/us` has 13 `.STR` files under `AAA/STR/` (incl.
`MOVIEOPN.STR`, ~37 MiB = 18088 × 2048-byte user sectors). Map marks
`form: 2`. `pack_runtime.py` copies the AAA tree as-is (2048-byte extracts);
it does **not** reassemble raw 2352-byte disc sectors. Streaming that
expects Mode2/Form2 sector layout + LBA seek into a cue/bin track needs
either a host ISO/track open or a port bridge from packed files → ring.

## PSY-Z surface @ `fac9bd58`

### Linked but stubbed / ASM gaps

| API | Host reality |
|---|---|
| `DecDCTReset` / `DecDCTin` / `DecDCTout` | decomp C → calls `MDEC_*` |

| `StCdInterrupt` | host `libcd.c` → **`NOT_IMPLEMENTED`** (real body still ASM in decomp) |

Movie sample in `vendor/psyz/samples/movie/` also needs real MDEC + VLC +
track I/O — same upstream gap.

## Blockers (ordered)

1. **PSY-Z MDEC / libpress** — `MDEC_*` stubs; soft `mdec.c` unwired;
   `DecDCTvlc` / `DecDCTvlc2` / `DecDCTvlcBuild` not real on host.
2. **STR streaming I/O** — `StCdInterrupt` stub; no track at movie LBA from
   packed `runtime/us` (need cue/bin **or** port stream-from-file for
   form-2 `.STR`).
3. **Movie audio (XA)** — depends on CD stream + SPU/CD mix; overlapping
   host audio gaps with P3.6 (`docs/P3.6_AUDIO.md` on main: SEP
   `_SsSeqPlay` stub). Opening movie audio is XA, not SEP, but still needs
   a working audio device + CD RT path.
4. **Pack format follow-up** — confirm whether 2048-byte packed STR is
   enough once a file-backed stream exists, or whether raw 2352 sectors
   are required for headers/XA.

## Not ticking Done-when
