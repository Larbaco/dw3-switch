## Call graph (game)

```
newGame / boot
  MODE_OPENING (0xE01) or MODE_OPENING_2 (0xE02) …
    STDWTITL scene → STDWTITL_startMovieTask(movieIndex)
      STDWTITL_tickMovie
        STDWTITL_startMoviePlayerTask(fileId, endFrame)
          FILE_TABLE.getPos(file, 0, &CdlLOC)
          DecDCTReset → StSetRing → StSetStream → CdRead2(stream)
          DecDCTvlcBuild / DecDCTvlc2 / DecDCTin / DecDCTout
          (XA audio via CdlModeRT on the same stream)

```

## Runtime pack (P1.6)

Owner `runtime/us` has 13 `.STR` files under `AAA/STR/` (incl.
`MOVIEOPN.STR`, ~37 MiB = 18088 × 2048-byte user sectors). Map marks
`form: 2`. `pack_runtime.py` copies the AAA tree as-is (2048-byte extracts).

**Sector adapter (Wave 3):** `port/movies/str_stream.c` synthesizes
Mode2/Form2 **2352-byte** sectors from those 2048-byte payloads (sync +
header + subheader + 2048 user + zero pad). PSY-Z `StCdInterrupt` reads
user data at offset 24. XA interleaved sectors (non-`0x0160` magic) are
skipped for the video ring; XA pull from the file bridge is Task 4.

On this bring-up host, point `runtime/us` at the packed tree (gitignored):

# Owner disc image (not in git):
