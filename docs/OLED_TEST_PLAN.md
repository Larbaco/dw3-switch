One ordered checklist for the owner's next Switch OLED session, built from the
[ROADMAP "Pending OLED checks"](ROADMAP.md#pending-oled-checks), the per-item
docs and the [release README](../platforms/switch/release/README.txt). Nothing
has been checked on the OLED unless a row says so. The owner's reports for
preview.41 to preview.45 (2026-10-27/28), preview.56 (2026-10-30) and preview.57 (2026-10-31) are in the
rows marked **PASSED**, **PARTIAL** or **NOT TESTED**. Each row links to the section that holds the full steps. If a doc and this
page disagree, the linked section wins.

Markers: **[GATE]** closes the Phase 5 gate. **[P5.1]** the 2 hour run.
**[LAUNCHER]** P6.24, not in any release, needs a manual NRO. Checks are for US
and EU unless marked; on EU, use at least two languages where the source says
so.

## ⚠ Destructive steps (owner rule, 2026-10-31)

A row marked **⚠ DESTRUCTIVE, optional** deletes, formats, resets, copies over,
or overwrites a save, the autosave, the shared store or a `port_options.cfg`
line. Run such a row only when all four steps below hold (they are cited in the
rows as §⚠1 to §⚠4). If one does not, write the row as NOT TESTED; nothing else
depends on it. The rule is in `AGENTS.md` (Owner's machine rules, rule 14).

1. **Verified backup.** Before the row, copy `sdmc:/switch/dw3/saves/`,
   `us/memcard/`, `eu/memcard/` and the `port_options.cfg` you will change to a
   new folder. Confirm the copy by a listing with sizes, or sha256 of each file,
   and name the folder in the report.
2. **Guard line.** The row names a `dw3.log` line that proves the safe path is
   active in this run. Store rows: `dw3-store: on dir=` and
   `read card0.dw3s crc ok`, with no `refused`. With the store OFF, a game
   format overwrites the flat `saveN.bin` and keeps no `.bak`, so store rows
   never run with the store off. If the guard line is missing, stop.
3. **Only the named target.** Touch only what the row names (card0 for store
   rows, the named slot, the named key or file).
4. **Restore.** After the row, close the game, copy the backup back over what
   the row changed, compare sizes (or sha256) with the backup, then start the
   game and Continue once to check that the save loads. Send the listing and the
   log lines.

Steps that only move the memcard folders aside (E3.1, G9.1, G9.7, G9.11 to
G9.13) and steps that delete old `.nro` files (G7.5, G9.15) are not marked: they
remove no save, cfg or store data. Keep the backup from Before you start anyway.
