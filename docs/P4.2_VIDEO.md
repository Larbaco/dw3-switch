# P4.2 Video — EGL present path

Status: **ticked** (2026-10-11). The game image presents the title
framebuffer on hardware. Frame time moved to P5.2.

## Goal

Present PSY-Z VRAM on the Switch display via the native libnx backend
chosen in P4.1 (`docs/SWITCH_BACKEND.md`). The original `gpu_hello` at
60 fps bar was the host-surface spike. The roadmap done-when is the title
framebuffer on hardware. 16.7 ms in field and battle is P5.2.

## What landed

| Piece | Location |
|---|---|
| EGL + OpenGL ES 2 init / swap / teardown | `platforms/switch/psyz_backend/nx_gpu.c` |
| Docked 1920×1080 / handheld 1280×720 | `dw3_nx_gpu_update_mode()` — tear down EGL, `nwindowSetDimensions` + crop, recreate |
| Vsync | `eglSwapInterval(display, 1)` |
| Sample | `platforms/switch/source/main.c` — clear-color cycle + FPS log on stderr |
| Link | Makefile adds `psyz_backend`, `-lEGL -lGLESv2 -lglapi -ldrm_nouveau` |

The game image presents `SoftwareRasterizer_GetVram()` through this
surface (`nx_gpu.c`). The Makefile `gpu_hello` clear loop is only the
`host_hello` sample.

## Build

```bash
# Linux/ext4 clone (preferred)
./tools/dk.sh make -C platforms/switch

# NTFS / drvfs checkout: rsync Switch tree to ext4, build, copy .nro back
DW3_DK_TMPBUILD=/tmp/dw3-dk-build ./tools/dk.sh make -C platforms/switch
# artifacts: platforms/switch/dw3-switch.nro (also under /tmp/dw3-dk-build/src/…)
```

Packages inside `devkitpro/devkita64`: `switch-mesa`, `switch-glad` (GLES2 via
mesa; sample links `libGLESv2`).

## Run on hardware

1. Copy `dw3-switch.nro` to the Switch SD (`/switch/dw3/` or hbmenu path).
2. Optional: `nxlink` so stderr FPS lines appear on the host (`gpu_hello: fps=…`).
3. Confirm the title framebuffer is on screen. Frame time is P5.2.
   Dock/undock while playing is P10.3.
4. Press **+** to exit.
