## Battle

| | |
|---|---|
| Label | `battle` |
| Mode / scene | Fight / report |
| Oracle | none |
| Verdict | **blocked**. `build/compare/battle/owner.state` is not on disk. No savestate was invented |

Battle stays here until the owner saves a mid-fight DuckStation state
(F2) to `build/compare/battle/owner.state`. A DuckStation state does not
boot `dw3-pc` into the fight, so this command is duck-only:

```bash
python3 tools/compare_harness/capture_pair.py \
  --label battle --duck-only --no-auto-load \
  --statefile build/compare/battle/owner.state \
  --settle-seconds 3 \
  --duckstation /mnt/windows/Jogos/emuladores/duckstation \
  --disc "/mnt/windows/Jogos/PS1/Digimon World 3/Digimon World 3.cue" \
  --bios "$HOME/.local/share/duckstation/bios/scph1001.bin" \
  --out build/compare
```

That command forces `EmulationSpeed=2` as well.
