# P3.9 — Reference comparison (title / field / battle)

Status: **boot automation active** on `phase3-harness`. Title/boot oracle
capture can run unattended at **EmulationSpeed=1 (100%)**. Field/battle
still blocked without shared `.mcr` / state. ROADMAP checkbox stays open
until all three sections have reviewed pairs (PNGs stay gitignored).

PS1 output (DuckStation) is the **visual oracle**. The PC build is the
subject under review. Pixel-perfect match is **not** required — GPU polish
may diverge; look for layout, HUD, wrong stage, crash/blank, or obvious
missing layers.

Harness: `tools/compare_harness/capture_pair.py`. Speed is forced via
`~/.local/share/duckstation/settings.ini` (`EmulationSpeed=1`, FF/turbo
capped, FF hotkey unbound) — see README.
