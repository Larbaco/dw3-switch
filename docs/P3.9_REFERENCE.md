```bash
  --settle-seconds 3 \
  --duckstation /mnt/windows/Jogos/emuladores/duckstation \
  --disc "/mnt/windows/Jogos/PS1/Digimon World 3/Digimon World 3.cue" \
  --bios "$HOME/.local/share/duckstation/bios/scph1001.bin" \
  --out build/compare
```

PC subject. Needs `DISPLAY`, `xdotool`, and `import`. Do not export
`DW3_FORCE_WIN`.

```bash
python3 tools/compare_harness/capture_pair.py \
  --label battle --pc-only \
  --runtime "$HOME/.cache/dw3-switch/runtime/us" \
  --pc-bin build/pc/dw3-pc \
  --encounter 1 \
  --out build/compare
```

`--pc-settle-seconds` overrides the 22s idle after `WFIGHTMN` loads.
`--encounter` selects `FIELDSTG_encounters[n]`.
