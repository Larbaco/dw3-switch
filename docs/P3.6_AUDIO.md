## Call graph (game)

```
main / boot
  SsInit()                          # engine/system/main.c
  …
  SOUND.init → initSound()          # sound.c
    SsSetTableSize(seqTable, 6, 16)
    SsSetTickMode(SS_NOTICK)        # US: manual ticks only
    SsStart2()
    …
    loadSoundBankInto(0, 1)         # system bank → slot 0

GFX.startVSyncCallback()
  VSyncCallback(vsyncCallback)      # display.c
    SsSeqCalledTbyT()               # every vblank under SS_NOTICK

Modes (title / field / battle / menus)
  SOUND.loadBank(id)                # slots 1↔2 alternate
  SOUND.updateLoading()             # FILE_CACHE + VAB/SEP open
  SOUND.playSound(packed)           # SEP or SsUtKeyOn
```

### Mode entry points

| Case | Path | APIs |
|---|---|---|
| Title music | `STDWTITL` loads bank `0x47`, plays `MUSIC(0x47, 0)` | `loadBank` → `SsSepPlay` |
| Field switch | Stage sets `FIELDSTG_state.music = MUSIC(bank, n)` | SEP stop/play + bank swap |
| Battle SFX | Fight overlays + system bank key-ons | `SsUtKeyOn` + SEP |
| Fades | `fadeOutSound` | `SsSepSetDecrescendo(..., 0x80, 0x3C)` |

## Implementation (this wave)

### Honesty

Upstream `decomp/src/libsnd/midiread.c` / `midinote.c` remain
`INCLUDE_ASM`. Host player is **`psyz/src/psyz/midiread_host.c`**:

- Logic ported from Xeeynamo/sotn-decomp `seqread.c` (MIT) onto PSY-Z’s
  PSY-Q 4.0 `SeqStruct` field names (`seq_ptr` cursor, `unk52`/`unk54`
  tempo, etc.).
- **Not** a matching decomp of retail `midiread` ASM.
- `_SsVmKeyOn` stand-in selects tones by note range and calls existing
  `_SsVmKeyOnNow` / `_SsVmDoAllocate`.
- Pitch bend / NRPN→VAB attr / `vmNoiseOn` still thin or stubbed.
- `SsSepSetDecrescendo` / `SsSeqSetDecrescendo` wired via
  `_SsSndSetVolData` + `SEQ_FLAG_20` (same pattern as crescendo);
  empty port stub removed from `port/psyz_missing/`.

psyz branch: **Larbaco/psyz `dw3-seq-sep`** @ `9e6c124` (branched from
bringup pin `47e281db` — does not race libcd/mdec).

### Evidence — title SEP (2026-10-10)

```bash
cmake -S platforms/pc -B build/pc -G Ninja \
  -DPSYZ_RENDERER=sdl3_gpu \
  -DSDL_X11_XSCRNSAVER=OFF \
  -DSDL_PULSEAUDIO=ON -DSDL_PIPEWIRE=ON -DSDL_ALSA=ON

rm -f sdlaudio.raw

  DW3_RUNTIME=runtime/us \
  timeout -s KILL 25 ./build/pc/dw3-pc --runtime runtime/us
```
