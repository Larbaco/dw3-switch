# P3.1 — 64-bit audit (overlays + stages)

**Status:** done on `phase3-pc-bringup` via match-neutral patch
`port/patches/0018-match-neutral-overlay-64bit-audit.patch` plus
`port/patches/0019-PORT_HOST-field-file-cache-watermark.patch`, with CMake
OBJECT target `dw3_p31_audit`.

## Scope

Same class of fixes as P2.4, applied under `src/field`, `src/battle`,
`src/cardgame`, `src/menus`, `src/debug` (plus `include/engine/gfx.h` for
`vsyncArg`):

- Literal `createTask` / `createTaskWithId` sizes → `sizeof(...)`
- Pointer-slot `childrenSize` → `N * sizeof(Task *)` / `STAGE_CHILDREN_SIZE`
- Stage select save mode arg → `STAGE_SELECT_MODE_ARG_SAVE` (`-0x80000000`)
- Task pointers stored as `void *` (scripts, `GFX.vsyncArg` / `vsyncFunc`)
- Archive / face / fighter / battle-menu address math → pointer + offset
- Field `FILE_CACHE.freeFrom` watermark → host heap offset (`0019`)

## Evidence

1. `tools/apply_patches.sh --check` passes with `0018` + `0019` in the
   series; `vendor/dw3_decomp` stays clean.
2. After apply, no remaining literal size args in the five audit dirs:
   `rg 'createTask(WithId)?\([^,]+,\s*(0x|[0-9])' …` → empty for
   non-`sizeof` forms (debug stubs use `sizeof(StageSelect)` /
   `sizeof(Task)`).
3. CMake OBJECT library `dw3_p31_audit` (`port/CMakeLists.txt`) compiles
   US inventory TUs under `_DW3_GAME_OPTS` including
   `-Werror=pointer-to-int-cast -Werror=int-to-pointer-cast
   -Werror=int-conversion`:
   `ninja -C build/pc dw3_p31_audit` → **432/432 objects** (success).
4. Linked Phase 2 units still build:
   `ninja -C build/pc dw3_engine_objs` succeeds under the same flags.
