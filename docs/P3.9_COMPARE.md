## Inputs (owner machine only)

Never commit disc images, BIOS, saves with personal data you care about,
or screenshot binaries. Outputs land under gitignored `build/compare/`.

| Input | Role |
|---|---|
| Own disc / `runtime/us/` | PC host data root (`docs/RUNTIME_LAYOUT.md`) |
| DuckStation + US BIN/CUE | Oracle boot; BIOS as DuckStation requires |
| Shared `.mcr` | Same slot-0 card for both sides (`port/memcard/README.md`) |
| `build/pc/dw3-pc` | Subject binary |
| Optional host env | `DW3_START_MODE`, `DW3_PROGRESS`, `DW3_MEMCARD_DIR`, … |

### Same-save contract

1. Produce or export a 128 KiB `memcard0.mcr` that both sides accept
   (PC host default under `DW3_MEMCARD_DIR`; DuckStation Import / card path).
2. Copy that file into **both** run roots before capture (do not let one
   side rewrite the card mid-harness unless the label is a save test).
3. Boot to a **settled frame** for the label (title idle, field after load,
   battle after fade-in or report screen — pick one per label and stick to it).

## Capture flow (target)

```
                    shared memcard0.mcr
                            |
            +---------------+---------------+
            v                               v
   DuckStation (oracle)              dw3-pc (subject)
   boot → settle → PNG               boot → settle → PNG
            |                               |
            +---------> build/compare/<label>/
                        duck.png   pc.png   pair.md
```

1. **Prepare** — copy `.mcr`, ensure `runtime/us` packed, build `dw3-pc`.
2. **Oracle** — launch DuckStation (GUI or CLI if available), load state /
   boot game, reach settled frame, save screenshot as `duck.png`.
3. **Subject** — run `dw3-pc --runtime …` with the same card dir and mode
   hints; grab a window/framebuffer PNG as `pc.png` (SDL screenshot,
   host hotkey, or future `DW3_CAPTURE_PATH=` hook).
4. **Review** — write `pair.md` (resolution, settle criterion, pass/fail
   notes). Optionally compose a side-by-side image locally; do not commit
   PNGs.

Stub entry point today: `tools/compare_ref.py` (`--dry-run` only).

## CLI (stub)

```bash
# Validate args / print plan; no disc, emulator, or binary required
python3 tools/compare_ref.py --dry-run \
  --label title --runtime runtime/us --save path/to/memcard0.mcr

# Future (not implemented; non-zero until capture exists):
python3 tools/compare_ref.py \
  --label field \
  --runtime runtime/us \
  --save runtime/us/memcard/memcard0.mcr \
  --duckstation /path/to/duckstation \
  --pc-bin build/pc/dw3-pc \
  --out build/compare
```

| Flag | Meaning |
|---|---|
| `--label` | `title` / `field` / `battle` (or free string for experiments) |
| `--runtime` | PC data root (default `runtime/us`) |
| `--save` | Path to shared `.mcr` (slot 0) |
| `--duckstation` | DuckStation executable (owner path) |
| `--pc-bin` | `dw3-pc` path (default `build/pc/dw3-pc`) |
| `--out` | Output root (default `build/compare`) |
| `--dry-run` | Document the plan and exit **0** without touching assets |
