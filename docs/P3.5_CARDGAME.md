# P3.5 — Card game (PC)

## Status (2026-10-10)

**Partial** on branch `phase3-cardgame` (worktree
`.worktrees/phase3-cardgame`, branched from `phase3-pc-bringup` @
`99133d5` to avoid fighting the P3.4 memcard fixer).

All four card overlays link into `dw3-pc`. Boot into `CARDGAME` works
(`DW3_START_MODE=0x700` or `DW3_FORCE_MENU=0x700:1` from field).
`DW3_FORCE_CARD_WIN` reaches prize apply. `STCRDABM` /
`STCRDDEK` / `STCRDSHP` open from field and return via
`DW3_AUTO_MENU_RETURN`.

**Not Done-when:** a card battle that returns to field after a win, and an
album (`GAME.cardsSeen` / `GAME.cards`) update driven by that win (or a
shop pack). Force-win applies `GAME.items[prize]++` then the host
segfaults before `CARDGAME` requestMode/`CARDGAME return` log (dummy SDL
GPU noise on this machine).

## Evidence aids

```bash
# Direct boot card battle + scripted win (prize item)
DW3_START_MODE=0x700 DW3_START_MODE_ARG=1 DW3_FORCE_CARD_WIN=1 \
  DW3_AUTO_PAD=confirm \
  ./build/pc/dw3-pc --runtime runtime/us

# Field → card battle
DW3_START_MODE=0x2D7 DW3_PROGRESS=4 DW3_FORCE_MENU=0x700:1 \
  DW3_FORCE_CARD_WIN=1 \
  ./build/pc/dw3-pc --runtime runtime/us

# Field → album / deck / shop → field
DW3_START_MODE=0x2D7 DW3_PROGRESS=4 DW3_FORCE_MENU=0x1200 \
  DW3_AUTO_MENU_RETURN=90 \
  ./build/pc/dw3-pc --runtime runtime/us
```
