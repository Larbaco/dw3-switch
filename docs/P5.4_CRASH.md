# P5.4 — Crash report to SD (2026-10-12)

## Landed

- Switch user-exception handler (`__libnx_exception_handler`) writes a
  readable text report to **`sdmc:/switch/dw3/crash_report.txt`**.
- Report fields: port version, reason, **`mode_file`** / **`stage_file`**
  (last restored mode overlay and sub-overlay / stage id), PC / LR / SP /
  FAR / ESR, and a pointer at `dw3.log`.
- Sink is opened on the main thread at boot (`dw3_nx_crash_install` from
  `boot_main.c` after SD mount + log open). Handler I/O uses libnx
  `fsFileWrite` (no stdio lock). Soft default: handler always linked;
  **no forced fault** in release / preview NROs.
- After the SD write, the handler `svcBreak`s so Atmosphere creport can
  still capture the fault under `sdmc:/atmosphere/crash_reports/`.
- Sub-overlay latch: `dw3_overlay_current_sub_file()` in `port/overlays`
  (mode latch unchanged for the mesh gate).

## How to force a fault (debug build)

Soft default is **off**. `tools/build_switch_game.sh` does not pass this
flag yet — configure CMake yourself (Docker/`tools/dk.sh` on this host):

```bash
./tools/dk.sh bash -c 'cmake -S platforms/switch -B /tmp/dw3-force-crash -G Ninja \
  -DCMAKE_TOOLCHAIN_FILE=/opt/devkitpro/cmake/Switch.cmake \
  -DDW3_NXLINK_STDIO=ON -DDW3_NX_FORCE_CRASH=ON && \
  cmake --build /tmp/dw3-force-crash -j"$(nproc)"'
```

Or set the cache entry in an existing nxlink build dir and rebuild:

```bash
cmake -B build/switch-nxlink -DDW3_NX_FORCE_CRASH=ON
cmake --build build/switch-nxlink -j"$(nproc)"
```

Boot that `.nro` once. After path init it deliberately null-writes; pull
`sdmc:/switch/dw3/crash_report.txt` over FTP / USB and confirm it names
`user exception`, registers, and `mode_file` / `stage_file` (often `0x0`
if the fault is before any overlay restore).

Software-only report without a CPU fault (for host unit checks later):

```c
dw3_nx_crash_write_report("manual smoke");
```

## Done when

A forced fault produces a readable report on SD — verified by the
`DW3_NX_FORCE_CRASH` path above on hardware or Ryubing with a mirrored
`sdmc:`.
