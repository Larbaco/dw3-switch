# P2.8 / E6 — Boot to title on PC

## Status (2026-10-10)

**Done** for the Phase 2 gate: PC host runs decomp `main` → `MODE_TITLE`
→ title loader → `STDWTITL_tickTitle` with a recognizable on-screen title,
and host libpad reports a connected controller so `PAD_PRESSED` can see
input. `vendor/` stays clean (patch-copy only).

Open follow-ups (not gate blockers): sprite/VRAM tiling glitches (logo /
copyright shredded; solid green bar), remaining literal `createTask(..., 4)`
sites outside the engine path.

## Run

```bash
cmake -S platforms/pc -B build/pc -G Ninja -DPSYZ_RENDERER=sdl3_gpu
cmake --build build/pc -j"$(nproc)"
# owner disc → runtime (Linux FS; see docs/DISC_SETUP.md)
python3 tools/pack_runtime.py --version us --disks disks/us --out runtime/us --force
./build/pc/dw3-pc --runtime runtime/us
# or: DW3_RUNTIME=runtime/us DW3_MEMCARD_DIR=runtime/us/memcard ./build/pc/dw3-pc
```
