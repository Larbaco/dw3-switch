# P3.4 — Menus and shops (PC)

## Status (2026-10-10)

**Partial.** All listed menu overlays are linked into `dw3-pc` and open from
field via `FIELDSTG_leaveField` (`DW3_FORCE_MENU`). Open → return to
`FIELDSTG` (`0x2d7`) is proven for `STSTATUS`, `STITSHOP`, `STGTRAIN`,
`STGDGLAB`, `STDGNAME`, and `STGMCARD` (load/save screen entry). `STPLNMET`
was already Done-when for P3.2.

**Not Done-when:** end-to-end pad-driven shop/gym/lab/naming flows, and
`STGMCARD` save completing through `MEMCARD_SYSTEM` → `_card_write` →
`.mcr`. Force-save reaches `writeInfo` but the engine memcard op stays
pending (`status==0`); P2.7 host `.mcr` I/O itself still works via
`tools/tests/test_memcard.py`.
