# P3.4 — Menus and shops (PC)

## Status (2026-10-10)

**Done-when met** (`READY_FOR_MAIN_ROADMAP_SYNC: P3.4`). All listed menu
overlays are linked into `dw3-pc` and open from field via
`FIELDSTG_leaveField` (`DW3_FORCE_MENU`). Open → return to `FIELDSTG`
(`0x2d7`) is proven for `STSTATUS`, `STITSHOP`, `STGTRAIN`, `STGDGLAB`,
`STDGNAME`, and `STGMCARD`. `STPLNMET` was already Done-when for P3.2.

**STGMCARD save (P2.7) proven:** force-save completes
`MEMCARD_SYSTEM.write` → `MemCardWriteFile` → `_card_write` →
`memcard0.mcr` mutation.

**STGMCARD load e2e proven:** `DW3_FORCE_MCARD_LOAD` + host
`_card_read` wrap (scratch buffer so PSY-Z stub does not clobber sectors)
→ `STGMCARD_loadSave` → return to `FIELDSTG`. Host force path accepts
version-matched payload when the quirky `&~` checksum disagrees.

**Pad START→status proven (no FORCE_FIELD_MENU):** LE host pad byte-order
fix in `psyz_pad_host.c` + `DW3_AUTO_PAD=status` pulses Start → Cross →
`field menu open (START)` → `MODE_STATUS` (`0x1000`) →
`AUTO_MENU_RETURN` back to `FIELDSTG`.

**STSTATUS Triangle UI cancel proven:** `DW3_FORCE_MENU=0x1000` +
`DW3_AUTO_PAD=cancel` → `STSTATUS Triangle cancel` →
`STSTATUS return` → `FIELDSTG` (`0x2d7`) with **no**
`DW3_AUTO_MENU_RETURN`.
