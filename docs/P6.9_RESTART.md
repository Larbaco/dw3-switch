# P6.9 in-process game restart

Controls, physical mappings, and diagnostic chord overlap: [HOTKEYS.md](HOTKEYS.md).

The title Port options shell exposes **Restart hotkey**, OFF by default. It is
session-only until P9.4 adds owner-storage persistence. Enable it from the
title shell, then hold the PS1 logical buttons **L1 + R1 + Start + Select**.
On PC's keyboard map this is Q + R + Enter + Backspace. Switch uses the same
logical pad buttons.

`port/options/restart.c` owns the chord, opt-in check, and P5.3
`memcard_host_flush_all()` call. A flush error cancels the restart and leaves
the current game running. A successful flush asks the existing game loop to
reset its in-memory `GAME` state, discard the active mode task, hide the
native title overlay, and continue through the same `dw3_game_main()` call. It does
not repeat PSY-Z, CD, audio, heap, pad, or graphics initialization, and it
does not format or edit save data.

## Boot target after restart

Restart re-runs `newGame()`, so it lands where a cold host boot lands. US goes
to the title. EU goes to the language selection (`CNTY_SEL`) with `LANGUAGE`
cleared, and the player chooses a language again. This matches a real PS1
reset (which returns to the country select) and means a language change needs
no host relaunch. It is not "skip to title with the old language".

The native title overlay (Switch GLES / PC SDL3 GPU: menu plaques, logo
texture, edge-fade level) is only hidden by title-task draws, and the title
task is discarded on restart. Before the fix, an EU restart from the title left
the overlay's active flags set while the mode became `CNTY_SEL`, so the title
menu and logo drew on top of the language screen (owner report, preview.26).
`dw3_port_title_overlay_reset()` now clears the overlay state as part of the
restart.

## Validation

On 2026-10-13, the PC game was run on a private Xvfb display using the owner's
existing runtime as read-only input and an empty memcard directory under
`/dev/shm`. The title shell enabled the setting; the chord produced
`saves flushed; returning to title in-process`, followed by the title mode
entry again. Host startup and `dw3_game_main()` entry did not repeat. The
options state-machine test confirms OFF by default and that the setting can
be enabled. The PC `dw3-pc` target linked successfully.

P6.9 remains open until the Switch build and hardware chord are validated and
a save written before restart is shown to load with Continue afterwards.
P9.4 remains open because the opt-in setting is not persisted.

### 2026-10-15, Ryubing (Xvfb, keyboard as Player 1)
