## Boot path (title → new game → name → field)

1. **Title:** default `MODE_TITLE` (`0xE00`) — `STDWTITL` (P2.8).
2. **New game (menu):** `title.c` → `GAME.funcs.requestMode(MODE_NEW_GAME, 0)`
   (`0x2D7`) → `FIELDSTG` + `FIELDSTG_pickStage` → **WSTAG780**.
3. **Intro door (script):** progress `0` starts event `0` (`script0`); ends
   with `SCRIPT_LEAVE(0x2D8, …)` → **WSTAG785** via `FIELDSTG_leaveField`.
4. **Name entry:** Online Center event `1` → `SCRIPT_LEAVE(0x500, …)` →
   `STPLNMET`; on exit `requestMode(0x2D8, 0)` → **WSTAG785** again.
5. **Next (not Done-when):** progress `1` event `3` leaves to `0x2D9`
   (**WSTAG790**, file 476) — not linked yet; continuing the FAST path
   SEGVs there (follow-up, not P3.2 Done-when).

WSTAG780/785 have **no** `stageSlots`; physical `SLOT_EXIT` triggers are
not used on these maps. The first-stage “door” is the intro
`SCRIPT_LEAVE`.

## Evidence aids (`0023` + pad host)

| Env | Role |
|---|---|

| `DW3_PROGRESS` | Story step after `newGame` (`0023`; `2` skips intro for free walk) |
