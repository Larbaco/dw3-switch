## Root cause (drawActor SEGV) — fixed

`DrawCallback.arg` was `s32`. On LP64, `layerAddSortedCallback(..., actor, ...)`
truncated the actor pointer to 32 bits before `layerRunCallbacks` called
`FIELDSTG_drawActor`. gdb before fix: `rdi=0x55b55558` (low 32 of a heap
actor); after `0022`: `actor=0x555555b55558` in `DW3_HOST_HEAP`,
`image` non-null. Same class of bug as `GFX.vsyncArg` in patch `0018`.

Fix: match-neutral `0022-match-neutral-drawcallback-void-arg.patch`
(`DrawCallback.arg` / add-callback APIs → `void *`). Vendor submodule clean.
